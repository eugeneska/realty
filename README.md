# realty

## Отправка заявок

Сайт отправляет заявки через `send.php` и SMTP Mail.ru. Скопируйте `.env.example`
в `.env` и заполните SMTP-логин, внешний пароль и адрес получателя.

Для работы требуется PHP 7.4+ с расширениями OpenSSL и mbstring. На nginx
дополнительно запретите доступ к скрытым файлам (`location ~ /\. { deny all; }`);
для Apache запрет уже задан в `.htaccess`.
